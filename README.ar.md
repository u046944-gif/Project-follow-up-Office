# TaskBoard – لوحة مهام الفريق

تطبيق ويب لتخطيط مهام الفريق: خطط ومراحل وبطاقات مهام، وعروض اللوحة والجدول والتقويم والمخطط الزمني والرسوم البيانية، وصفحة "مهامي"، ولوحة إدارة. يدعم العربية والإنجليزية، ويمكن تثبيته كتطبيق على الهاتف والحاسوب.

يعمل على أي استضافة ويب. البيانات وتسجيل الدخول والتحديث المباشر عبر **Supabase** (الباقة المجانية تكفي للبداية). قاعدة البيانات نفسها تفرض الصلاحيات، فلا يصل لأي شخص إلا ما يسمح به دوره.

## ما تحتاجه

- حساب مجاني في **Supabase**: https://supabase.com
- أحد الخيارات: حساب **Bolt** ‏(https://bolt.new)، أو أي استضافة مواقع ثابتة (Netlify أو Vercel أو Cloudflare Pages)، أو Node.js على جهازك.

## 1. إنشاء قاعدة البيانات (5 دقائق)

1. في Supabase أنشئ مشروعًا جديدًا (**New project**)، واختر منطقة قريبة من المستخدمين، واحفظ كلمة مرور قاعدة البيانات.
2. افتح **SQL Editor ← New query**.
3. افتح الملف `supabase/migrations/20261110000000_taskboard.sql`، وانسخ محتواه كاملًا، والصقه، ثم اضغط **Run**. يمكن تشغيله مرة أخرى دون ضرر.
4. من **Project Settings ← API** (أو زر **Connect**) انسخ:
   - **Project URL**
   - مفتاح **anon / publishable** (لا تستخدم مفتاح `service_role` السري في هذا التطبيق أبدًا)

## 2. إعداد تسجيل الدخول

في Supabase افتح **Authentication ← URL Configuration**:

- **Site URL**: عنوان الموقع الذي ستستضيف عليه التطبيق.
- **Redirect URLs**: أضف العنوان نفسه، وأثناء التجربة أضف عنوان معاينة Bolt أو `http://localhost:5173`.

تأكيد البريد الإلكتروني مفعّل افتراضيًا، فيصل للمستخدم الجديد بريد تأكيد قبل الدخول. يمكن تغيير ذلك من **Authentication ← Providers ← Email**.

## 3أ. التشغيل على Bolt

1. ضع ملفات المشروع في مستودع على GitHub.
2. في Bolt استورد المستودع من GitHub: من الصفحة الرئيسية اختر GitHub ثم المستودع، أو ضع `bolt.new/` قبل عنوان المستودع، مثل: `https://bolt.new/github.com/USER/REPO`.
3. اربط Supabase: داخل المشروع اضغط أيقونة **Database** ← **Advanced** ← **Connect**، واختر مشروع Supabase من الخطوة 1.
4. إذا لم يملأ Bolt الإعدادات تلقائيًا، أضف القيمتين الموجودتين في `.env.example` ‏(`VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`).
5. اضغط **Publish / Deploy**، ثم أضف العنوان المنشور إلى Site URL وRedirect URLs في Supabase (الخطوة 2).

## 3ب. التشغيل على أي استضافة أخرى

<div dir="ltr">

```bash
cp .env.example .env        # ضع فيه عنوان ومفتاح Supabase
npm install
npm run dev                 # تجربة محلية على http://localhost:5173
npm run build               # ملفات النشر في مجلد dist
```

ارفع مجلد `dist` إلى أي استضافة. في Netlify أو Vercel أو Cloudflare Pages: اربط مستودع GitHub، واجعل أمر البناء `npm run build` ومجلد الإخراج `dist`، وأضف متغيري `VITE_SUPABASE_…`.

## 4. أول دخول

1. افتح الموقع واضغط **إنشاء حساب**. **أول حساب يصبح المالك** (مسؤول دائم).
2. أرسل عنوان الموقع لفريقك. كل شخص ينشئ حسابه، فيظهر في **لوحة الإدارة ← المستخدمون ← بانتظار الموافقة**.
3. وافق عليه، واختر دوره، وأضفه إلى الخطط.

| الدور | الصلاحيات |
|---|---|
| المالك | كل صلاحيات المسؤول، ولا يمكن تغييره. |
| مسؤول | إنشاء الخطط وحذفها، وإدارة الأعضاء والمراحل والتصنيفات والأدوار، ورؤية كل الخطط. |
| عضو | إضافة المهام وتعديلها وإسنادها ونقلها وإكمالها في خططه، وحذف المهام التي أنشأها. |
| مشاهد | قراءة خططه وتصديرها فقط. |
| بانتظار الموافقة | حساب جديد لم يُعتمد بعد، لا يرى شيئًا. |
| بلا وصول | محظور، لا يرى شيئًا، ويبقى سجله محفوظًا. |

## 5. التثبيت كتطبيق

بعد الاستضافة على HTTPS:

- **الحاسوب (Chrome / Edge)**: اضغط **تثبيت التطبيق** في القائمة الجانبية، أو أيقونة التثبيت في شريط العنوان.
- **أندرويد (Chrome)**: اضغط **تثبيت التطبيق** في القائمة الجانبية، أو من القائمة ← **تثبيت التطبيق**.
- **آيفون / آيباد (Safari)**: زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

يفتح بعدها في نافذة مستقلة بأيقونته الخاصة.

## التخصيص

- **النصوص العربية**: `src/i18n.js`.
- **الألوان والخطوط**: المتغيرات أعلى `src/styles.css`.
- **اسم التطبيق وأيقونته**: `index.html` و`public/manifest.webmanifest` و`public/icons/`.

## ملاحظات أمنية

- مفتاح anon/publishable مصمم ليكون علنيًا، وقواعد أمان قاعدة البيانات (Row Level Security) هي التي تحدد ما يقرأه ويعدّله كل مستخدم. تم اختبار هذه القواعد لكل الأدوار.
- لا تضع مفتاح `service_role` السري في التطبيق أبدًا.
- لإزالة شخص نهائيًا: اجعل دوره **بلا وصول**، أو احذف المستخدم من Supabase ← Authentication ← Users.
